# Templates

Copy templates when they remove friction.

Do **not** fill every template by default.

The rule is:

> Use the smallest template that prevents future confusion.

No Obsidian plugins are required. If you use Obsidian's core Templates plugin, set the template folder to `mechatronics/templates`.

Delete, ignore, or simplify templates that do not earn their keep.

## Naming convention

Prefer names that sort by date and explain the artifact:

```txt
YYYY-MM-DD_short_description.md
YYYY-MM-DD_scope_ch1_back_emf.png
YYYY-MM-DD_pid_step_response.png
```
